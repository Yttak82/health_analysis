# Health Analysis
Statistisk analys av hälsodata i Python.

## Projektbeskrivning
Projektet innehåller beskrivande statistik, visualiseringar, simulering, konfidensintervall, hypotesprövning och power-analys.

## Dataset
Analysen använder health_study_dataset.csv`

## Python_version
Python 3.14.7

## Notebook
Analysen finns i `notebooks/analysis.ipynb` i branchen `del1`

## Reproducerbarhet
Projektets Python-beroenden finns i `requirements.txt`
